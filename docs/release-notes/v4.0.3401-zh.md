# CC Switch Custom v4.0.3401

基于 CC Switch 官方正式版 `v4.0.34`（`d243d970af87e13a243b005d6af73d0375050486`），包含自 `v4.0.33` 起的 68 个上游提交。[本版安装包](https://github.com/asd260531078/cc-switch-custom/releases/tag/v4.0.3401) · [官方更新说明](v4.0.34-zh.md)

## 本次更新

- 技能仓库支持 GitLab、Gitea 和 Forgejo 的公开 HTTPS 仓库，包括自建实例和 Codeberg。会话管理支持删除已关闭的 Antigravity CLI 会话。
- 开启自动下载更新后，启动时发现新版会立即下载。WorkBuddy 手动添加的模型可以设置思考强度，S3 同步可清除本机配置。
- 修复 Gemini CLI 获取模型列表、Codex 的 Copilot 图片输入识别、国内对象存储的 S3 同步和 Skills 失效链接导致同步失败等问题。
- 保留 Claude Desktop/Pi 仅导入和显式启用、Pi 独立 UUID、Codex 深链认证及模型目录、网站 Logo、Token-AI/MX-AI 优先预设和本仓库独立更新源。任意用量脚本仍需显式启用。

## 升级和回退

- 数据库 schema 从 26 升至 27。原有 GitHub 技能仓库沿用 `github.com`，已安装的旧 Skills 保留数据、启用状态和仓库关联。
- 安装前退出旧版，备份数据库、应用设置、账号状态及相关客户端配置。升级时会尝试生成数据库快照，默认位于应用数据目录下的 `backups/`。
- 回退到 [v4.0.3301](https://github.com/asd260531078/cc-switch-custom/releases/tag/v4.0.3301) 时，先退出应用并另存升级后的数据，再恢复升级前的 schema 26 数据库及对应配置。旧版会拒绝打开 schema 27 数据库。回退后，升级期间新写入的数据需另行保留。
- 已用隔离数据库验证启动升级、重复打开和恢复升级前快照。SQLite 完整性、旧 Skills 的仓库与启用状态、供应商 Logo 和自定义价格均通过检查。
- Qwen4 Max 默认价格用于本地费用估算，单位为美元/百万 Token。价格种子只补缺失条目，已有自定义价格优先。[QwenCloud 价格表](https://www.qwencloud.com/models/qwen4-max#pricing)

## 下载

- Windows 10/11 x64 使用 MSI 或绿色版 ZIP。Windows 安装包未配置 Authenticode 证书。
- macOS 12+（Apple Silicon 和 Intel）使用 Universal DMG。安装包使用 ad-hoc 签名，未做 Apple 公证。
- 安装沿用原应用标识、协议和数据目录。更新包通过本仓库的 Tauri 公钥校验。
