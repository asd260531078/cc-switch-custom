# CC Switch Custom v3.20.207

本版基于已发布的定制版 v3.20.206，保留官方 CC Switch v3.20.4 功能及本仓库的独立更新通道。

## 本版更新

- Codex 供应商深链支持逗号分隔的 `models` 参数，也可从内嵌配置的 `modelCatalog.models` 读取模型列表。导入确认框显示默认模型和模型列表，保存后生成 Codex 模型目录。仅提供旧版 `model` 参数的链接继续按原方式导入，不据此推测其他可用模型。
- “设置 → 关于”移除指向官方仓库的 Star 请求和 `ccswitch.io` 官网按钮；保留本项目 GitHub 入口、更新日志及更新功能。

## 升级与回退

本版没有新增数据库迁移；仍使用 v3.20.206 已引入的 schema 19。从 v3.20.205 或更早版本升级时，首次启动前请在旧版设置中备份或导出数据。回退到 schema 18 的旧版时，请退出应用并按官方备份恢复流程恢复旧版数据，避免旧版直接打开升级后的数据库。

本版沿用原应用标识、数据目录及 `ccswitch://` 协议，会替换同位置的旧应用。安装前退出旧版。Windows 若拒绝安装较低版本，先卸载程序并保留数据，再安装目标旧版。

macOS 安装包使用 ad-hoc 签名，未做 Apple 公证；Windows 安装包未配置 Authenticode 证书，系统可能提示未知发布者。自动更新仍使用本项目独立的 Tauri 签名密钥校验。
