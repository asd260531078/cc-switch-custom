# CC Switch Custom v4.0.4301

本版合入官方 v4.0.41 至 v4.0.43，基于官方正式标签 v4.0.43（`754fed72`）。

- 授权中心支持 CodeBuddy 和官方账号额度手动刷新模式，托盘可切换 Antigravity 官方账号并查看余额。Copilot 支持 Auto 路由。
- 「应用」页可管理已安装的 OpenCode 2，会话管理可读取 OpenCode 2.4 的助手回复。改进流式请求首字和速度统计，修复 macOS 菜单栏图标位置及 Codex 直连切回官方 ChatGPT 后部分会话无法继续的问题。已经遇到该问题的旧会话需新开会话。
- Claude Code 的供应商终端沿用卡片自带的模型菜单。Claude Desktop 的深链与表单保留多个模型及各档选择，Codex、Gemini 和 Grok Build 表单保留导入模型候选。
- 保留 Claude Desktop 和 Pi 的仅导入与显式启用、Codex 深链认证和模型目录、供应商网站 Logo、模型自定义价格、Token-AI/MX-AI 预设顺序及独立更新通道。

官方细节见 [v4.0.41](v4.0.41-zh.md)、[v4.0.42](v4.0.42-zh.md) 和 [v4.0.43](v4.0.43-zh.md)。

## 安装与回退

Windows 10/11 x64 提供 MSI 和便携 ZIP。macOS 12 及以上提供 Universal DMG，支持 Intel 与 Apple Silicon。自动更新沿用本项目的 Tauri 签名。macOS 包采用 ad-hoc 签名，Windows 安装包未配置 Authenticode 证书。

从 v4.0.4002 升级时，SQLite schema 从 27 升至 28。迁移会补齐 CodeBuddy 的 MCP 和 Skills 开关，旧数据默认关闭这两项，原有应用开关继续生效。升级前先使用内置备份功能，退出应用后另存应用设置、账号状态及相关客户端配置。回退时退出应用并另存升级后的数据，恢复升级前的数据库及相关配置，再启动[上一版 v4.0.4002](https://github.com/asd260531078/cc-switch-custom/releases/tag/v4.0.4002)。旧版无法打开 schema 28 的数据库。
