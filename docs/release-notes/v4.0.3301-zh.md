- 数据库 schema 从 24 升至 26，为 `mcp_servers`、`skills` 增加 Copilot CLI、WorkBuddy 独立开关，旧记录缺省关闭；沿用官方幂等补列，保留已有应用开关和数据。
- 新模型价格以美元/百万 Token 存储，用于本地费用估算；新增缺失种子不覆盖自定义价格。Hydrogen Orchestrator 沿官方回退到基础模型价格，自定义精确价格优先，历史未定价记录可能补算。本地估算不代表订阅额度消耗或真实扣费。Gemini Carbon 种子沿官方使用截至 2026-11-30 的介绍价，后续需要跟进官方更新。
- 实际升级前应备份数据库、设备设置、账号状态与客户端配置/会话。Codex 会话兼容处理和费用补算会写入本地状态；回退须退出应用并恢复升级前的对应数据，不能仅换回旧安装包或将 schema 26 数据库交给 schema 24 版本。
- 同步前的本地回退标签：`backup/before-upstream-v4.0.33-20261116`，指向 `5e4931f1`。本次测试仅使用隔离数据，不安装或启动真实 App。
