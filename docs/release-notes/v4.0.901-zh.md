# CC Switch Custom v4.0.901

同步官方 [v4.0.9 正式版](https://github.com/farion1231/cc-switch/releases/tag/v4.0.9)，基线提交 `8845b1ef799aa8810b864b122de6af5f4629de10`，合入 v4.0.4 之后的 111 个上游提交（v4.0.5–v4.0.9）。源码同步不代表安装包已发布。

## 更新内容

- Codex 支持 GitHub Copilot 托管账号，新增子代理模型与推理强度设置；重整供应商表单、模型选择和默认模型流程。
- 修复 Codex 新建线程和自动化在部分 Chat 上游报 400、xAI Responses 报 422，以及第三方压缩请求的工具兼容问题。
- 支持读取压缩后的 Codex 历史会话，提供会话压缩开关；改善仅装桌面版时的模型列表获取与失败诊断。
- 本地路由新增连接地址，支持 WSL2 客户端；修复 Windows 重启提示、非 ASCII 路径、MSI 图标和 Claude Code npm 安装问题。
- 优化额度展示、历史用量热力图和 Skills 更新，新增日志入口，修复启动语言、macOS 本地网络授权和模型列表请求头。
- 同步官方用量统计修复：Claude 1 小时缓存写入、Codex 缓存写入、部分网关的缓存命中，以及跨应用供应商统计。

## 定制兼容

保留 Claude Desktop/Pi 只导入与显式启用、Codex API Key 深链认证和模型目录、网站 Logo、Token-AI/MX-AI 与官方 API 预设，以及本仓库独立更新源、公钥和发布通道。新增预设追加在原列表后，保留已有选择 ID。关于页继续移除官方 Star 请求及官网推广入口，README 不恢复赞助宣传。

应用版本统一为 `4.0.901`，提供四种语言更新摘要。CI 保留按改动范围检查和手动 WSL2 完整套件，发布仍以 Windows x86_64 和 macOS Universal 为目标，先创建草稿。

## 数据与回退

数据库 schema 仍为 20，无新增结构迁移。新增配置字段采用兼容默认值，模型定价只补缺失条目，不覆盖用户自定义价格。缓存费用修复影响本地统计估算，不发生真实扣费。

会话压缩开关默认不启用；用户主动打开后由 Codex 执行压缩，旧工具可能无法读取 `.jsonl.zst`。回退旧版前需关闭不兼容的新功能并备份客户端配置；旧版不能读取压缩会话，但会话仍由 Codex 管理。

源码同步阶段只进行本地同步和隔离测试；其后的构建发布验收见下文。未安装 App 或修改真实用户配置。
