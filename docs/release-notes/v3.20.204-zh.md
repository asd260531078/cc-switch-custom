## 本版更新

- 支持 `app=pi` 供应商一键导入，提供“仅导入”和“导入并在 Pi 中启用”。启用时添加原生供应商，保留默认模型、已有供应商和其他应用配置。
- Pi 导入使用 OpenAI Chat Completions 基础地址及明确的模型 ID；校验输入、拒绝命令/变量凭据，并在保存失败时回滚本次原生配置变更。Pi 的 Logo、用量查询和展示元数据在保存、编辑及刷新后保留。
- 支持导入链接中的 `iconUrl` 网站 Logo；导入预览、供应商卡片和编辑页使用同一图片，支持手动修改或清除地址。
- Logo 按完整图片地址分别缓存，主站、分站和自定义域名可显示各自图片；加载失败时回退内置图标，不阻塞导入和切换。图片下载仅接受公网 HTTPS 和受限的光栅格式，不携带供应商 API Key。
- 新增 Token-AI、MX-AI 预设及图标，排序为 Token-AI、MX-AI、自定义配置；默认使用各自官网域名，并按客户端协议添加必要路径。
- 精简其他中转和聚合供应商预设，保留官方直连入口、自定义配置和用户已保存的供应商。
- 移除设置页的官方站点按钮。
- 修正 Logo 缓存过期测试在 Windows 上更新文件时间戳所需的文件打开权限。

## 安装与回退

macOS 使用 ad-hoc 签名，未经过 Apple 公证；Windows 未配置 Authenticode 证书，系统可能提示未知发布者。Tauri 更新包沿用本项目独立签名密钥校验。

安装版沿用官方应用名、标识、`ccswitch://` 协议及数据目录，会替换同位置的旧应用。安装前退出旧版，并通过设置备份或导出数据，不要同时运行两版。

本版没有数据库表结构迁移，Logo 地址保存在可选供应商元数据中。旧版可以读取原有配置，但使用旧版编辑并保存供应商可能丢失新增 Logo 地址，需要重新导入或填写。

回退时退出应用并备份数据，再安装明确的旧版本。Windows 若拒绝降级，先卸载程序并保留数据；仅在配置不兼容时按原应用恢复流程使用安装前备份。
