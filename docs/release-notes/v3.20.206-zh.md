# CC Switch Custom v3.20.206

本版合入官方 CC Switch v3.20.4 的功能与修复，继续保留本仓库的供应商预设、深链导入、外部 Logo 和独立自动更新通道。

## 本版更新

- 新增 MiniMax Code 管理，包括供应商、MCP、Skills、提示词、会话浏览与用量统计；默认模型和登录仍由 MiniMax Code 管理。
- 合入 Codex 网关工具与图片转换、已保存 API Key 和账号绑定等修复，并更新 Claude Desktop Linux 配置、OpenCode 模型选择与请求日志等功能。上游完整变更见[官方 v3.20.4 说明](v3.20.4-zh.md)。
- 本仓库的官方 API 预设加入 `gpt-6-sol`、`gpt-6-luna` 和 `claude-opus-5-5`；已有默认模型及已保存供应商配置不会自动改写。

## 升级与回退

本版将数据库 schema 从 18 升至 19，为 MCP 和 Skills 增加 MiniMax Code 的启用字段。**首次运行新版前，请在旧版设置中备份或导出数据，并妥善保存备份。**应用会尝试建立迁移前数据库备份，但备份失败不阻止迁移。回退旧版时，不要让旧版直接打开已升级的数据库；退出应用后按官方备份恢复流程恢复旧版数据。

本版沿用原应用标识、数据目录及 `ccswitch://` 协议，会替换同位置的旧应用。安装前退出旧版。Windows 若拒绝安装较低版本，先卸载程序并保留数据，再安装目标旧版。

macOS 安装包使用 ad-hoc 签名，未做 Apple 公证；Windows 安装包未配置 Authenticode 证书，系统可能提示未知发布者。自动更新仍使用本项目独立的 Tauri 签名密钥校验。
