## 本版修复

- Codex 深链导入默认生成 `requires_openai_auth=false`，无需导入后手动修改认证字段。
- 普通链接与内嵌配置继续使用供应商自己的 API Key；启用、切回官方、再次启用时正确保留密钥。
- 兼容“保留官方登录”设置。开启时运行配置可能使用 `requires_openai_auth=true` 来保留账号状态，请求仍使用第三方供应商自己的凭据。
- 保留链接的启用选择和首个供应商的原有行为，不迁移数据库、不批量改写已有供应商。旧网站如果仍提示手动修改认证字段，使用本版新导入后可直接按需要启用。

## 安装与回退

macOS 使用 ad-hoc 签名，未经过 Apple 公证；Windows 未配置 Authenticode 证书，系统可能提示未知发布者。Tauri 更新包沿用本项目独立签名密钥校验。

安装版沿用官方应用名、标识、`ccswitch://` 协议及数据目录，会替换同位置的旧应用。安装前退出旧版，并通过设置备份或导出数据，不要同时运行两版。

回退时退出应用并备份数据，再安装明确的旧版本。Windows 若拒绝降级，先卸载程序并保留数据；仅在配置不兼容时按原应用恢复流程使用安装前备份。
