# CC Switch Custom v4.0.3801

基于官方正式版 v4.0.38（`2c084ec7`）。从上一个公开定制版 v4.0.3401 升级，可获得官方 v4.0.35 至 v4.0.38 的更新。

- 新增插件管理页面，支持 Claude Code、Codex 等客户端。技能仓库支持使用按站点保存的访问令牌读取私有仓库。
- WorkBuddy 支持一键导入供应商，Pi 新增 Mistral 原生协议预设。保留 Claude Desktop 和 Pi 的仅导入与显式启用、Pi 独立标识、Codex 深链认证和多模型目录、网站 Logo、Token-AI/MX-AI 预设顺序及独立更新通道。
- ChatGPT 账号卡片支持 GPT-6.2。修复 Codex 手动思考等级未生效、部分工具名冲突和经路由生成的会话切回官方模型时无法继续的问题。
- 修复部分用量重复统计。非官方供应商可为新产生的本地路由请求设置费用倍率，缺省为 1。保留用户为大小写不同的模型 ID 单独设置的价格。
- 修复 macOS 从访达打开时误报 npm 工具无法运行、全屏窗口从托盘恢复被遮挡，以及 Windows 的 Oh My Pi 会话恢复命令无法在 PowerShell 使用的问题。

各版详细变更见 [v4.0.35](v4.0.35-zh.md)、[v4.0.36](v4.0.36-zh.md)、[v4.0.37](v4.0.37-zh.md) 和 [v4.0.38](v4.0.38-zh.md)。

## 安装、升级与回退

Windows 10/11 x64 使用 MSI 安装包或便携 ZIP。macOS 12 及以上使用 Universal DMG，支持 Intel 和 Apple Silicon。自动更新沿用本仓库的 Tauri 公钥。macOS 包采用 ad-hoc 签名，Windows 安装包未配置 Authenticode 证书。

从 v4.0.3401 升级时，数据库 schema 保持 27。启动时会补建模型价格索引并补充缺失的内置价格。会话正文索引会重建。升级前退出应用，备份数据库、应用设置、账号状态及相关客户端配置。若需回退，退出应用并另存升级后的数据，安装[上一公开版 v4.0.3401](https://github.com/asd260531078/cc-switch-custom/releases/tag/v4.0.3401)，按需恢复升级前备份。
