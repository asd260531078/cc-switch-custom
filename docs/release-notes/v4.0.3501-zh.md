# CC Switch Custom v4.0.3501

基于 CC Switch 官方正式版 `v4.0.35`（`61c43c03`），合入 `v4.0.34` 之后的 20 个上游提交。[官方更新说明](v4.0.35-zh.md)

## 本次更新

- Claude Code 和 Claude Desktop 的 ChatGPT 账号卡片更新 Codex 客户端版本标识，可以获取账号可用的 GPT-6.2 模型。
- 会话管理可展开查看 Codex `/goal` 的完整目标与状态，请求详情可复制完整请求 ID。
- 修复 Codex 聚合模式和打开终端时的 Responses-Lite 错误、Codex 转 Chat 格式时压缩上下文后的空消息，以及 Claude Code 自动模式在部分思考模型上被拒的问题。
- 用量查询的自定义日期限制在已有用量记录的最早日期与今天之间。Skill 的托管副本缺失时仍可卸载。
- 保留 Claude Desktop/Pi 仅导入和显式启用、Pi 独立 UUID、Codex 深链认证和模型目录、网站 Logo、Token-AI/MX-AI 预设及本仓库更新源。

## 升级和回退

- 从 `v4.0.3401` 升级时，SQLite schema 维持 27。GPT-6.2 Sol/Astra 采用 Standard 短上下文价格估算本地用量，单位为美元/百万 Token。缓存写入使用 30 分钟档，已有自定义价格优先。[GPT-6.2 Sol 价格](https://developers.openai.com/api/docs/models/gpt-6.2-sol) · [GPT-6.2 Astra 价格](https://developers.openai.com/api/docs/models/gpt-6.2-astra)
- 安装前退出旧版，备份数据库、应用设置、账号状态及相关客户端配置。回退时先退出应用并另存升级后的数据，再安装明确的 [v4.0.3401](https://github.com/asd260531078/cc-switch-custom/releases/tag/v4.0.3401)。需要撤回升级期间的配置或数据改动时，恢复对应的升级前备份。
