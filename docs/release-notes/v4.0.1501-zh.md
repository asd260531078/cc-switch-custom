# CC Switch Custom v4.0.1501

同步官方 [v4.0.15 正式版](https://github.com/farion1231/cc-switch/releases/tag/v4.0.15)，基线提交 `79e754ab1b6ed50da57dae1d0faecab4b3b52f1c`，合入 v4.0.12 之后的 98 个上游提交（v4.0.13–v4.0.15）。本次范围是本地源码同步与隔离验证，未推送、发布、安装或运行真实 App，未修改真实用户配置。

## 更新内容

- **Desktop 与 Codex：**Desktop 采用统一的直连、路由和聚合模式，支持托管账号获取模型；Codex 增加自动审批模型、聚合子代理模型和推理强度设置。切回直连先确认，路由切换仅在客户端配置实际变化时提示重启。
- **用量显示：**支持多币种与自定义汇率、侧栏指标、日志列、视图记忆和趋势图样式。金额仍以美元保存，换算仅用于展示；新增 Gemini 4 Argon 标准档介绍价及多项会话/子代理统计修复。
- **稳定性：**修复 Windows 设置文件残留导致重置、Codex 升级检测超时误卸载、终端 PATH、WSL Hermes 会话读取；修复 Gemini 签名回放、DeepSeek 工具历史、Codex 远程压缩和路由重试参数；改善 Skills 大文件下载与云同步慢速传输。
- **其他：**采用新版 macOS 图标、Hermes 图片输入声明及新增云预设；同步 GPT 上下文窗口 272K 上限和 Claude 1M 声明更新。此上限属于 CC Switch 的保守客户端配置，并非所有真实上游模型能力的上限。

完整上游说明：[v4.0.13](v4.0.13-zh.md)、[v4.0.14](v4.0.14-zh.md)、[v4.0.15](v4.0.15-zh.md)。

## 定制兼容

- 保留 Desktop/Pi「只导入」与显式启用双动作。Desktop 只导入不写当前指针、设备状态或客户端文件；显式启用需要映射的卡时通过官方模式控制器启动路由，保留原直连指针。已处于路由/聚合时仅切换对应目标，保留模式。预览说明路由运行及 Desktop 重启要求；异步导入命令把同步模式操作放到阻塞任务执行。
- 保留 Pi 独立 UUID、原始模型 ID、默认仅保存、显式启用不改默认模型、动态凭据拒绝规则；同时采用官方 OpenCode 中文名称安全 ID 和导入后状态刷新。
- 保留 Codex 深链 API Key 模板缺省 `requires_openai_auth=false`、显式配置与模型目录；实际启用仍采用官方登录保留和 bearer token 投影，不强制改写所有运行配置。
- 保留完整 `meta.iconUrl`、后端公网 HTTPS 校验与图片缓存、失败回退及不阻塞导入；本地上传图标仍可用。任意用量脚本缺省禁用，固定套餐查询维持既有规则。
- 保留九应用 Token-AI、MX-AI、官方 API 预设、旧选择 ID 与顺序；官方新预设追加尾部，原预设按上游更新。保留独立 updater 地址/公钥、应用标识与现有发布平台。Windows 绿色版直达下载改为本仓库，未发布的 ARM64 架构回退本仓库发布页。
- 保留 README/关于页的推广移除约定及现有 CI 范围筛选和手动 WSL2 全量策略；同步官方 Hermes WSL2 只读 WAL 测试门禁。

## 数据与回退

数据库 schema 仍为 **20**，没有新增结构迁移。新增显示选项使用兼容可选字段，费用换算不改数据库金额、不产生真实扣费。Gemini 4 Argon 输入/输出/缓存读取为每百万 Token **2 / 10 / 0.10 美元**，已对照 [Google 官方定价](https://ai.google.dev/gemini-api/docs/pricing#gemini-4-argon)；介绍价至 2026-11-30，后续应随上游更新。价格种子只补缺失条目，既有自定义价保留。补充修正同名大小写双行的查询歧义：先查原始 ID 精确行，再按规范化候选查价，回退顺序固定；不合并或删除既有价格行。

**真实启动仍可能更新数据：**旧 Desktop 映射当前项会迁到设备本地路由状态，保留该路由目标并调整直连回退指针；启动时可能回填历史零费用，Pi 子代理从新导入起统计。Windows 损坏设置在恢复保存前备份原始字节，已经被旧版本重置的数据不能凭此恢复。旧版本保存设置可能丢弃新增显示选项。

实际安装前应备份 CC Switch 数据库、设备 settings、live-state、客户端配置和 Desktop configLibrary，以及已有 Codex 会话与迁移备份。回退时先退出应用和相关客户端，保留新版数据副本，再恢复对应旧数据/配置并换回旧包；只替换二进制不能撤销模式转换、费用回填或会话迁移。

源码回退锚点：本地标签 `backup/before-upstream-v4.0.15-20261018-01a14b0f`，对应同步前 `31fbb7f`。本次未安装、未访问真实上游账号、未运行真实卸载/云同步。
