# CC Switch Custom v4.0.1201

同步官方 [v4.0.12 正式版](https://github.com/farion1231/cc-switch/releases/tag/v4.0.12)，基线提交 `51ac86f1c59abfefabadebd05ec5a5415b8ad72c`，合入 v4.0.9 之后的 101 个上游提交（v4.0.10–v4.0.12）。源码同步阶段只准备了本地源码并完成隔离验证；本次构建发布的验收记录见文末。没有安装或运行新版 App，也没有修改真实用户配置。

## 更新内容

- **工具管理：**「应用」页补齐安装、升级、卸载和安装冲突诊断。多处安装时可以选择卸载目标，执行前再次核对来源、路径与命令；升级前检查适用的 Node 版本要求。同步 Windows 自动更新后 PATH 补全、Grok Build 新安装方式和卸载结果提示修复。
- **本地模型与云预设：**新增「本地」分组，提供 Ollama、LM Studio、llama.cpp、vLLM 预设，本机请求绕过应用代理与系统代理。补充 Ollama Cloud、Groq、Hugging Face、Vercel AI Gateway 等云平台预设，并同步 StreamLake 等地址更新。预设新增和地址更新只影响新添加的供应商，不改写现有供应商。
- **图标与深链：**支持上传本地图片，保存到「我的图标」后复用；图片规范化为小尺寸 PNG。深链采用后端暂存、前端读取并确认的处理流程，改善冷启动、窗口重建、重复通知及新旧链接交错时的可靠性；吸收 `apiFormat`、供应商配置保留、站长接入指南和在线生成器。
- **用量与云同步：**用量页新增首字时间，修复 Codex 中途换模型、分页父会话的子代理统计及分叉会话重复扫描；后台会话扫描改为每 10 分钟一次，用量页打开时立即扫描并按所选间隔更新。新增 Sub2API 用量模板，套餐类固定额度查询在各应用中新添加或导入时默认开启，显式关闭仍生效；修复云同步恢复 Skills 后无法重试的问题。
- **其他修复：**同步 Responses 流正常结束后又报错、工作区读取失败造成内容错位、Skills/MCP 批量失败提示、未保存编辑保护、Pi 会话速度估算及 WSL 路径写入修复；改善 Windows 全屏页面闪烁和更新后读取模型列表的 PATH。新增社区土耳其语，不支持的系统语言首次启动使用英文。

上游完整说明见 [v4.0.10](v4.0.10-zh.md)、[v4.0.11](v4.0.11-zh.md)、[v4.0.12](v4.0.12-zh.md)。其中深链导入按钮、网站 Logo 和脚本启用规则以本仓库下列定制约定为准。

## 定制兼容

- **Claude Desktop / Pi 双动作：**继续提供「只导入」与显式「导入并切换 / 在 Pi 中启用」，这两类供应商不展示通用激活开关；其他应用沿用官方导入后激活开关。只导入不改客户端当前启用状态。
- **Codex 深链：**保留本项目的 API Key 认证处理和模型目录配置，并吸收官方对供应商连接字段的保留及危险配置拒绝规则。
- **网站 Logo：**保留原始完整 `iconUrl`，包括大小写、路径和查询参数；预览及卡片通过后端 Logo 缓存加载。导入不等待图片下载，不把网站 URL 转换成上传图标，也不清除原 URL；本地图片上传和图标库继续可用。
- **脚本启用：**链接携带任意 `usageScript` 时，缺省保持禁用，只有显式 `usageEnabled=true` 才启用。未携带自定义脚本的 coding-plan 固定额度查询沿用官方默认启用规则。
- **预设与更新源：**保留 Token-AI、MX-AI 和官方 API 入口，新增预设不替换既有选择 ID；保留本仓库独立更新源、公钥和发布通道。README 不恢复赞助宣传区或 GitHub Sponsor 入口，关于页继续保留本项目既有移除约定。

应用源码版本统一为 `4.0.1201`，随源码附带四种语言更新摘要。构建发布状态以文末验收记录及本仓库实际 Release 为准。

## 数据与回退

数据库 schema 仍为 **20**，本次没有新增数据库结构迁移。新增图标库保存在 settings 的 JSON 数据中，沿用兼容配置格式，不新增数据库表；图标功能不要求手工改库。

**安装并启动新版后，部分已有数据会自动处理。** v3.20 及更早通过官方账号走路由留下的 Codex 会话，启动时会从旧 `cc-switch-official` 分组迁回内置 `openai` 分组。迁移以实际 Codex 配置目录为单位，仅在符合条件时执行，并保留迁移前的会话备份；手动恢复且仍在使用旧供应商表时会跳过。此操作修改的是会话记录，不是 `config.toml`，也不是执行 Git 源码同步时立即运行的迁移。

真实安装和首次启动前，应备份所有实际使用的 CC Switch 数据目录及各客户端配置目录，尤其是数据库、Codex 会话目录和原有会话迁移备份。启动还可能更新路由模式下 Claude Code 的 haiku 别名；Codex 分页子代理用量会在后续扫描中补导，Pi 速度估算只对新导入记录生效。后台不经路由的用量最多晚 10 分钟进入统计，打开用量页会立即扫描。

如需回退，应先关闭 CC Switch 和相关客户端，保留新版产生的数据副本，再恢复升级前对应的数据库、客户端配置及 Codex 会话目录备份，然后启动旧版。只替换 App 二进制不会撤销会话迁移或恢复旧客户端配置；不要在 App 运行时覆盖这些目录。

源码同步和发布验收不调用真实安装、卸载、更新、登录、付费 API 或云同步，不触及真实客户端配置。
