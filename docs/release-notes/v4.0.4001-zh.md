# CC Switch Custom v4.0.4001

本版合入官方 v4.0.39 和 v4.0.40，基于官方正式标签 v4.0.40（`f19a9d4f`）。

- Grok 官方卡支持绑定授权中心的 xAI 账号并切换，插件页支持 Antigravity CLI。用量统计按供应商和模型展示缓存命中率，小米 MiMo 可查询可用余额与 Token Plan 额度。
- 优化数据库、本地路由、会话搜索和应用列表加载。备份可设置总大小上限，默认不限制。修复 Claude Code 和 Claude Desktop 流式请求首字超时、长响应内存增长、一键导入失败仍弹出确认框，以及 Windows 仅装 Codex 桌面版时插件页误报未安装的问题。
- 加强 MCP 深链、用量脚本、SQL 导入及非本机路由监听的检查。保留 Claude Desktop 和 Pi 的仅导入与显式启用、Codex 深链认证和模型目录、网站 Logo、模型自定义价格、Token-AI/MX-AI 预设顺序及独立更新通道。

详细变更见 [v4.0.39](v4.0.39-zh.md) 和 [v4.0.40](v4.0.40-zh.md)。

## 安装与回退

Windows 10/11 x64 可用 MSI 安装包或便携 ZIP。macOS 12 及以上可用 Universal DMG，支持 Intel 和 Apple Silicon。自动更新沿用本项目的 Tauri 签名。macOS 包采用 ad-hoc 签名，Windows 安装包未配置 Authenticode 证书。

从 v4.0.3801 升级时，SQLite schema 仍为 27，主库改用 WAL，会话正文索引在首次搜索时重建。升级前先用内置备份功能保存数据库，退出应用后另存应用设置、账号状态及相关客户端配置。如果进程异常退出，应将数据库与仍存在的 `-wal`、`-shm` 文件一并保留，避免丢失尚未合并的数据。回退时退出应用并另存升级后的数据，安装[上一版 v4.0.3801](https://github.com/asd260531078/cc-switch-custom/releases/tag/v4.0.3801)，按需恢复升级前备份。
