# CC Switch Custom v4.0.401

同步官方 [v4.0.4 正式版](https://github.com/farion1231/cc-switch/releases/tag/v4.0.4)，基线提交为 `a29a4f3868e9c6ffc2212957cfa66a718642e344`，包含此前 v4.0.3 的新增功能和修复。源码版本不代表安装包已发布。

## 更新内容

- 支持 OpenCode 2.0 原生供应商配置，兼容旧格式；在 JSON 编辑器中保留注释并校验配置。
- MCP 和提示词改为整页编辑，离开存在未保存修改的编辑页时提醒保存。
- 新增备份位置与空间占用总览、ChatGPT 订阅的 Codex Credits 余额展示。
- 修复思考关闭后仍使用高推理强度、Skill 导入未部署到勾选应用、部分流式工具调用丢失，以及用量表格漏计缓存 Token 等问题。
- 合入项目切换器默认隐藏、窄窗口速度列显示和 macOS 重启窗口前置等官方调整。

## 定制兼容

保留 Claude Desktop/Pi 只导入与显式启用、Codex API Key 深链和模型目录、网站 Logo、自定义配置/Token-AI/MX-AI 优先顺序、官方 API 预设，以及本仓库独立更新源和签名。关于页继续不显示官方 Star 请求及官网推广入口。

四处应用版本统一为 `4.0.401`，并提供四种语言的本版更新摘要。发布工作流预设为正式版，仍先创建草稿并执行既有签名和更新元数据检查；本次同步不会触发发布。

## 数据与回退

数据库 schema 仍为 20，无新增数据库迁移。新增 OpenCode 原生格式标记为可选元数据，旧配置继续兼容；旧版本不具备新版格式支持。实际安装或修改真实客户端配置前应备份，回退时退出应用、安装明确旧版，必要时恢复对应配置备份。此次验证只使用隔离目录和虚拟数据。

Windows 10/11 真机安装、真实上游请求、真实用户配置升级和安装包签名验收需在对应发布或安装任务中完成。
