## 本版更新

- Claude Code、Claude Desktop、Codex、Grok Build、OpenCode、OpenClaw、Hermes 和 Pi 补齐 OpenAI、Claude、Gemini、Grok 官方 API Key 预设；Gemini CLI 补充 Gemini 官方 API Key 预设。
- 预设选择器按“自定义配置、Token-AI、MX-AI”开头排列，搜索时自定义配置始终保留第一位，其他预设继续按搜索条件过滤。
- 支持 Responses 的客户端中，Token-AI / MX-AI 新建预设默认使用 Responses 和 `/v1` 接口地址；Gemini CLI 保持原生 Gemini 协议。
- 修正 Codex 与 Grok Build 选择 Claude 官方 API 预设时的认证字段，并在切换预设时同步重置，避免沿用上一个预设的认证方式。
- 保留已有官方账号登录入口及 API Key 操作；Pi 使用独立供应商标识，避免影响原生登录凭据。已有供应商配置不会自动迁移或覆盖。
- 延续 Pi / Claude Desktop 一键导入、网站 Logo 与 Codex 深链认证修复。

## 安装与回退

macOS 使用 ad-hoc 签名，未经过 Apple 公证；Windows 未配置 Authenticode 证书，系统可能提示未知发布者。Tauri 自动更新继续使用本项目独立签名密钥校验。

安装版沿用现有应用名、标识、`ccswitch://` 协议及数据目录，会替换同位置的旧应用。安装前退出旧版，并通过设置备份或导出数据，不要同时运行两版。

本版没有新增数据库迁移，预设调整仅在选择预设时填入配置。回退时退出应用并备份数据，再安装明确的旧版本。Windows 若拒绝降级，先卸载程序并保留数据；仅在配置不兼容时按原应用恢复流程使用安装前备份。回退到不支持网站 Logo 的旧版后，编辑保存供应商可能丢失 Logo 地址。
