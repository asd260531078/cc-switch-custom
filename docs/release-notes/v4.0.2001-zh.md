## 数据与回退

数据库 schema 从 **20 升到 23**，新增 Antigravity、Kimi 的 MCP/Skills 开关与 Oh My Pi 的 MCP 开关，既有记录缺省关闭，不自动启用客户端。迁移应保留原开关且可重复执行。新增客户端配置、账号、设备排序和托盘选项沿官方兼容默认值处理。

用量费用单位仍为每百万 Token 的美元价格及美元统计金额；只是本地估算/展示，不发生真实扣费。价格种子补缺失行，官方历史价格修正仅匹配原始种子数值，不覆盖已自定义的价格；保留本地大小写精确查价优先规则。单行定价仍不能表达全部区域、阶梯、缓存 TTL 和套餐差异。

Kimi K3/K3.1 Pro/Highspeed 与 MiniMax M3.1 Flash 的新增或修正价格已对照 [Kimi 官方平台](https://platform.kimi.ai/) 和 [MiniMax 官方定价](https://platform.minimax.io/docs/pricing/overview)。其他价格沿用上游种子，并非逐项独立核价；Qwen 各地区与阶梯可查 [阿里云价格表](https://www.alibabacloud.com/help/en/model-studio/model-pricing)，不能把单一估算价格视为所有端点的实际账单。

真实启动可能执行 schema 迁移、账号/配置兼容处理与会话用量导入。实际安装前须备份 CC Switch 数据库、设备 settings/live-state、各客户端配置、Desktop configLibrary、既有会话和迁移备份。回退时退出应用与相关客户端，保留新版副本，再恢复迁移前数据/配置和旧安装包；**schema 23 的数据库不能直接交给 schema 20 的旧版**。

本地源码回退标签：`backup/before-upstream-v4.0.20-20261026`，对应 `9d3e07a`。本任务未修改真实用户配置、数据库、系统凭据或已安装应用。
